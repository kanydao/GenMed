# GenMed Project Page

Static project page for **GenMed: A Pairwise Generative Reformulation of Medical Diagnostic Tasks**.

GitHub Pages source:

```text
Branch: main
Path: /docs
```

The site is self-contained apart from Google Fonts and the `<model-viewer>` CDN dependency used for interactive 3D mesh comparison.

## Contents

```text
index.html
static/css/style.css
static/js/main.js
static/js/compare.js
static/images/
static/models/
```

The `static/models/` meshes are web-ready GLB assets used by the interactive comparison section.
